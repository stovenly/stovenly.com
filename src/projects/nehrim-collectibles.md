A browser tool that reads a Nehrim save and shows which collectibles are still missing.

## Features

- Reads Nehrim save files (.ess)
- Missing items as a list and as map pins
- Tracks all collectibles:
  - Magic Symbols
  - Sparks of Fire Caps
  - Ice Claws
  - Almanacs of Conjuration
  - Potions of Encumbrance
