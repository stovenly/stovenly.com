A browser tool that reads an Enderal save and shows which collectibles are still missing.

## Features

- Supports Enderal SE and Enderal Classic save files (.ess)
- Missing items as a list and as map pins
- Tracks all collectibles:
  - Magic Symbols
  - Mystical Symbols
  - Phasmalist Souls
  - Vatyra Fragments
  - Ice Claws
