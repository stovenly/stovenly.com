Learn the Flags

2026 · Browser
  • Try it here
  • Source code

A browser app for memorizing the flags of the world.

Features

  • Covers:
    • Sovereign states
    • US states
    • Canadian provinces and territories
    • Territories and dependencies
    • States with limited recognition
    • Historical flags
    • International organizations
  • FSRS-6 spaced repetition
  • Daily lessons and reviews
  • Questions that get harder as recall improves
  • Missed flags retried in the same session
  • Lookalike flags taught side by side
  • Memory hook for every flag
  • Regional map for every flag
  • Progress export and import
  • Unlockable badges

Disclosure

AI coding assistants were used to accelerate the implementation of this project.
